# gh-dash

Config for [gh-dash](https://github.com/dlvhdr/gh-dash), plus the
three vendored Version 14 theme variants in `themes/` (the active one
is pasted into `config.yml`'s `theme.colors` block). gh-dash is a `gh`
CLI extension, not a standalone install -- `gh extension install
dlvhdr/gh-dash` first.
