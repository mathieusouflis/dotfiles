# zed

Zed editor settings, keymap, tasks, and the commit-message convention
its AI agent follows. Deliberately doesn't cover everything under
`~/.config/zed` -- `prompts/`, `conversations/`, `settings_backup.json`,
and `keymap.json.*.bak` are generated/backup state, not dotfiles.
Zed's Version 14 themes are installed as an extension through Zed
itself, not vendored here.
